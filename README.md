## 🧩 2. Structure of `.h` and `.cpp` Files
- **`.h` files** ✍️: Used to **declare** classes, functions, and features.  
- **`.cpp` files** 💻: Where you **implement** the logic declared in `.h`.

Example:
- `hcm_campaign.h` → contains class and method declarations.  
- `hcm_campaign.cpp` → contains the actual implementation of those methods.
